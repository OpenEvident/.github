# Support

## Getting help

**Documentation.** Start with the README and the `docs/` directory in the repository you are using. Most common questions about setup, configuration, and usage are answered there.

**Bug reports and feature requests.** Use the issue templates on the relevant repository. Search existing issues first; your question or problem may already be tracked.

**General questions and discussion.** If your question is not a bug report or a feature request, for example you want to ask how something works, discuss a design idea, or share how you are using a project, open a GitHub Discussion on the relevant repository if one is enabled, or open an issue and we will point you in the right direction.

## What to expect

OpenEvident projects are maintained by volunteers on their own time. There is no guaranteed response time and no service level agreement. We read everything and do our best to respond, but please be patient.

## Commercial support

We do not currently offer paid support contracts. If that changes, it will be noted here and in the relevant project's README.

## Reporting a security issue

Security vulnerabilities should not be reported through the channels above. See [SECURITY.md](./SECURITY.md) for how to report them privately.
